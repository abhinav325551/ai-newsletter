## THE BIG THING ### Cloudflare Bakes OpenAI Directly Into Its Global Edge Network — and the Agentic Race Just Got More Serious Cloudflare and OpenAI have announced a partnership that brings GPT-4.5 and Codex directly into Cloudflare's Agent Cloud, giving enterprises a single platform to build, deploy, and scale AI agents at the edge. This isn't a standard API reseller arrangement. The integration is infrastructure-level: agents running in Cloudflare's network can invoke OpenAI models within the same execution environment where Cloudflare already handles request routing, security filtering, and global load balancing. The practical upshot is that enterprises no longer have to stitch together a model provider, a compute layer, a security perimeter, and a deployment pipeline independently — Cloudflare is collapsing that stack. For companies already running significant traffic through Cloudflare's network, the path to production agentic workflows just got meaningfully shorter. The context here matters. Cloudflare has been systematically repositioning itself from "CDN and DDoS protection vendor" to "AI infrastructure company" for the better part of two years. Its Workers AI platform, AI Gateway (which proxies and logs model calls), and Vectorize (its vector database) were all stepping stones toward exactly this kind of vertically integrated offering. OpenAI, meanwhile, has been under real competitive pressure to move beyond the raw API and secure durable enterprise distribution — Azure OpenAI is its primary enterprise channel, but that locks OpenAI into Microsoft's go-to-market motion. Cloudflare represents an independent, high-trust distribution layer that reaches enterprises who are explicitly *not* all-in on Azure. Including Codex specifically signals that code generation and software automation agents are a priority use case, not an afterthought. The broader implication is that the agentic infrastructure market is consolidating faster than most predicted. The pattern you should recognize: hyperscalers and edge providers are becoming the primary battleground for AI model distribution, and model providers that don't secure these partnerships risk being commoditized or outmaneuvered. Anthropic has AWS Bedrock. Meta's open weights are everywhere. Google has its own stack. OpenAI securing Cloudflare — a vendor with a genuinely cross-cloud, cross-region footprint — is a strategically distinct move because Cloudflare sits *in front of* infrastructure rather than being infrastructure itself. Agents deployed here inherit Cloudflare's existing security posture, which addresses one of the most cited enterprise blockers for agentic adoption: the inability to enforce access controls and audit trails on autonomous systems acting on behalf of users. What to watch: First, whether AWS, Google Cloud, or Azure respond with competing edge-native agent deployment announcements in the next 60–90 days — this deal will put pressure on all of them. Second, how Cloudflare prices this offering; if Agent Cloud is priced as a premium tier, it signals Cloudflare believes the margin is in orchestration, not compute. Third, watch for Anthropic's next infrastructure partnership announcement — Claude is notably absent from this stack, and Anthropic will need a comparable edge distribution story. Finally, monitor enterprise adoption velocity: the real test of whether collapsing the agent stack actually reduces time-to-production, or whether the harder problems (agent reliability, tool access governance, cost unpredictability) simply move up the stack and remain unsolved. --- *Source: OpenAI Blog. Note: "GPT-4.5" appears in the source material described as "GPT-5.4," which does not correspond to any publicly confirmed OpenAI model designation as of this writing — treat that specific model name as potentially erroneous or (unconfirmed) until OpenAI clarifies.*

## Models & Research This week's research drop skews heavily toward capability-expansion at the edges — physics reasoning, multimodal video synthesis, and procedural 3D generation — rather than another round of raw benchmark leapfrogging on standard NLP tasks. The most intellectually interesting thread is the push to ground neural systems in hard physical constraints, whether that means thermodynamics for solar forecasting or simulator-based RL for Olympiad-level physics. Taken together, the papers signal a maturing field that is increasingly uncomfortable with models that are fluent but physically incoherent.
- **[arXiv] RL on physics simulators enables Olympiad-level reasoning without large QA datasets** — The paper explicitly frames simulator-generated experience as a scalable alternative to internet-scraped QA pairs, directly addressing the data bottleneck that limits DeepSeek-R1-style training beyond math-heavy domains. [Link](http://arxiv.org/abs/2604.11805v1) - **[arXiv] Physics-informed state space models eliminate nocturnal power hallucinations in solar forecasting** — Current deep learning models produce physically impossible outputs (power generation at night, temporal phase lags during cloud transients); the proposed SSM architecture hard-codes atmospheric thermodynamic constraints to prevent these failure modes in off-grid PV systems. [Link](http://arxiv.org/abs/2604.11807v1) - **[arXiv] OmniShow unifies text, image, audio, and pose conditioning for human-object interaction video generation** — The system targets high-value commercial applications — e-commerce product demos, short-form video — where current video generators fall apart on fine-grained physical contact and object manipulation. [Link](http://arxiv.org/abs/2604.11804v1) - **[arXiv] LottieGPT tokenizes Lottie vector animations for autoregressive generation, bypassing raster-space models entirely** — This is a meaningful architectural departure: rather than distilling vector output from diffusion models, it treats animation parameters as a native token sequence, preserving resolution-independence and direct editability. [Link](http://arxiv.org/abs/2604.11792v1) - **[arXiv] Pair2Scene generates dense 3D indoor scenes from local object-pair relations without LLM spatial reasoning** — The authors explicitly critique LLM/VLM-based scene generation for failing at precise spatial reasoning, positioning their local-dependency model as more reliable for scaling beyond training-distribution density.
