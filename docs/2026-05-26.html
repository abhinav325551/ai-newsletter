## Models & Research This week's research batch skews heavily toward infrastructure and controllability rather than raw capability scaling — a signal that the field is increasingly grappling with *how* to deploy and extend foundation models reliably, not just how to make them bigger. The most intellectually interesting thread runs from simulation-ready 3D reconstruction through agentic system design: researchers are building the scaffolding that turns impressive demos into production-grade pipelines. Notably absent this week: any major frontier model release or benchmark-topping result from a leading lab.
- **[arXiv] TriSplat moves 3D scene reconstruction toward simulation-ready outputs** — Unlike most Gaussian splatting methods that require expensive post-hoc mesh extraction, TriSplat claims to produce simulation-compatible primitives directly from sparse views in a feed-forward pass, which would meaningfully shorten the pipeline for robotics and embodied AI applications. [Link](http://arxiv.org/abs/2605.26115v1) - **[arXiv] MobileGym introduces verifiable RL environments for mobile GUI agents** — The platform uses deterministic, JSON state-based judging to produce ground-truth outcome signals — a critical gap in prior mobile agent benchmarks where reward hacking via visual mimicry was largely unchecked — and supports low-cost parallel rollouts via browser hosting. [Link](http://arxiv.org/abs/2605.26114v1) - **[arXiv] "Scaling the harness" paper reframes agentic AI bottlenecks as system design, not model size** — The authors argue that auditable, modular execution layers around foundation models are now the primary constraint on agentic AI progress, a pointed counter-narrative to labs still leading with parameter counts as the primary metric of capability. [Link](http://arxiv.org/abs/2605.26112v1) - **[arXiv] AnyScene targets long-tail autonomous driving scenarios via fine-grained BEV-conditioned generation** — Existing occupancy-guided video synthesis methods are reference-frame-dependent, limiting coverage of rare safety-critical edge cases; AnyScene proposes arbitrary Bird's-Eye View layout conditioning as the control mechanism, which has direct implications for synthetic data pipelines at companies like Waymo and Cruise. [Link](http://arxiv.org/abs/2605.26113v1) - **[arXiv] InstructSAM unifies arbitrary-instruction instance segmentation by bridging VLMs with SAM3** — The framework casts instruction-driven segmentation as a set-structured query prediction problem, using a learned query bank as the interface between the vision-language reasoning layer and the segmentation backbone — an architectural choice that avoids the brittleness of prompt engineering at inference time. [Link](http://arxiv.org/abs/2605.26102v1) - **[arXiv] Prism targets a largely ignored MLLMs deployment problem: catastrophic forgetting during continual instruction tuning** — The paper identifies severe engineering bottlenecks in Multimodal Continual Instruction Tuning (MCIT) research reproducibility and proposes a plug-in infrastructure for scalable experiments, signaling that the community lacks even basic shared tooling for this problem class. [Link](http://arxiv.org/abs/2605.26110v1)
